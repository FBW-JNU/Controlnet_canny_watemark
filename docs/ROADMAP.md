# 后续实验：以消息恢复为主

以下是待完成研究任务，不是已有实现或性能承诺。

1. **稳定选择的全新内容验证**：首先评估“原E探测→像素稳定区域→有序曲线”的新顺序，冻结6探测筛选、输入准入、编码和解码；以同内容/同prompt-seed配对比较source-only与stable。整内容保留，无载体也计失败；报告可编码率、每位正确、整串正确、错误与擦除、质量及按内容区间。
2. **固定接收辅助条件**：先把原曲线辅助作为明确基线；再单独比较仅公共码本、管道Mask、矩形Mask、RGB-only。薄管Mask本身含形状，不混称完全盲检测。
3. **定位与形变分开诊断**：独立核验少量原位置→输出真实边缘对应，避免用真实消息挑最像码字的路径。用真实对应区分定位错误、形变未保留和分类中心偏差。
4. **实际多曲线消息串**：每图先选少量分散稳定载体，同时写入均衡随机消息；配对生成并测载体间共同错误/擦除。比较等位移、等载体、等消息长度预算的重复码和RM软译码，报告净有效载荷及整包正确率。离线模拟只用于设计，不能替代实图。
5. **部分存活**：保持码本/幅度，在随机缺失和中央/端部/单侧缺口分别评价；分开已定位后删观测与先删边再同步。门槛前拟合、软信息与最终擦除同时保存，避免只数幸存点。
6. **MAT可选分支**：先要求真实孔内补线支撑、完整细线、硬化后四码字闭环。比较普通修复后编码、消息约束修复投影前/后、直接几何编辑。投影支撑只来自孔外的样本必须显式记录。输入未过不得汇报RGB收益。
7. **质量与生成泛化**：扩prompt/seed、控制强度与采样器，后续才扩模型和压缩/缩放/裁剪。较大幅度已有反例，不把提高位移当作自动提升；同时关注Mask外全图影响。

clean仍保留为配对生成与自然扰动对照，但不再把低误报/Key认证作为当前阻塞任务。若以后用于实际归属，再另立合法码字/校验约束；不要把随机消息匹配50%当作认证证据。
