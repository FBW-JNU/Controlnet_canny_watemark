# 目标、阶段与当前边界

当前主目标是消息恢复。clean/marked存在性和Key归属暂不作为主要验收项。

| 阶段 | 本版实现 | 边界 |
|---|---|---|
| A 原始E多轮传输 | `probe-generate`固定未修改E，3prompt×2seed | 探测成本6次生成/内容 |
| B 稳定区域筛选 | `stability.screen_pixels`先统计原边缘像素保留与位移离散度 | 输出边缘近邻是代理观测，可能误匹配纹理 |
| B 筛后提候选 | `source_curves(stable_edges)`，再复核整段路径 | 不从完整E预选候选；筛后碎裂可能丢失长曲线 |
| C 输入准入/编码 | `select`选首个稳定且实际二值输入闭环通过的候选；S1/ST2编码 | 本版准入是轻量四消息闭环，不等同历史4A九状态准入 |
| C 可选MAT | 独立普通领域MAT修复入口 | 消息约束W+优化/投影尚未移植；历史未证明RGB收益 |
| D 冻结生成 | 普通SD1.5 ControlNet，512²/DDIM20/CFG5/eta0/control1/float32 | 配对消息共享CPU初始噪声；无训练 |
| E 消息接收 | 原曲线辅助局部对应与联合拟合；消息或擦除 | 沿用S/4A函数；不是旧稳定75%使用的4B接收器 |
| E 多载体纠错 | 尚待实现 | 不能用四符号调制或离线RM模拟代替真实纠错 |

先筛出的stable_edges是原Canny上被支持的像素集合，不等于待编辑Mask。曲线从该图骨架追踪得到，在分叉、端点、转角或长度边界切段，通常24–160px、弦长≥12px。轻度样条保留有序参数；随后Mask在选中曲线周围建立。完整曲线坐标、规范方向、弧长参数和码本随reference保存。

S/T位移在端点为零；源曲线即便已经弯曲也叠加相对位移。接收端在原参考附近重新寻找真实输出边缘，沿原参数拟合偏移，并非识别“最终像不像S”。缺失点保留原t位置，不将残片重置成完整0–1曲线。

初筛规则目前固定：距输出Canny最近边缘≤3px，支持≥5/6次，每prompt至少1/2；支持视图中，最近点位移向量相对逐坐标中位数的欧氏距离中位数≤2px。随后要求整段匹配≥5/6、每prompt≥1/2、锚点合格≥5/6、匹配中位距离≤3px。无需额外隐式配准：当前要求所有图像同尺寸同坐标，错位数据必须先显式配准。

这些阈值和“区域先筛选”组合是新方案，实现和开发验证不等于有效消息信道已被验证。历史75%属于旧候选顺序及旧接收器，保留作对照。

完整消息正确率=整串全部正确/全部尝试；逐bit恢复率=正确位/全部写入位；错误和擦除必须分别报告。clean无消息真值；与独立均衡随机目标比较的逐bit期望50%，常数解码也能达到，故不能用它单独证明有效传输。若需要每图必出bit，应冻结强制判决回退规则并另报结果；当前不随机回填擦除。
