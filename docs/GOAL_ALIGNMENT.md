# 研究目标与实现核对

截至 2026-11-12，本包采用用户最新研究口径：先研究已知载体条件下的消息通信，clean-vs-marked 和 Key 归属暂不作为主要目标。不删除历史脚本中的存在性分数，但新 CLI 不使用该阈值判消息。

| 目标阶段 | 现有实现 | 当前边界 |
|---|---|---|
| 原始 E → 连通曲线候选 | 骨架邻接图、路径追踪、转折与长度切段、轻度样条、去重 | 非语义角点选择；端点可能是人为切点 |
| A：跨 prompt/seed 传输探测 | Stage1 多轮 clean；最新稳定配对每图 6 次探测 | 探测与最终评价 prompt/seed 分开；需评估推理成本 |
| B：稳定 Mask | ≥5/6匹配、每 prompt≥1/2、锚点与距离要求，再检查输入可写性 | 薄管 Mask 是区域参考，不证明每个像素都存活 |
| C：消息几何编码 | 1 bit S，2 bit S/T；移动真实二值像素 | 任意源曲线可写性不保证；四码字无额外纠错 |
| C 可选：MAT 约束补线 | 冻结 MAT，优化 W+，投影前后及直接编辑对照 | 未通过可靠输入闭环；无此分支的新 RGB 成绩 |
| D：冻结 ControlNet | 修改条件图驱动 SD1.5 Canny，配对共享噪声 | 没有训练 ControlNet；没有潜变量水印 |
| E：RGB → 几何 → 消息 | 参考辅助对应、实际观测点联合拟合、码本判决/擦除 | 使用原曲线、参数化与参考码本，非 RGB-only 盲解码 |
| E 后续：部分存活与联合纠错 | 部分缺失实图观测测试；离线 RM/重复码 | 多载体真实生成和端到端长消息纠错尚未完成 |

## 编码与端点

从真实边缘图沿连通路径提取曲线，在分叉、自然端点、明显转折或长度边界处分段。候选主要长24–160px，弦长至少12px。首尾坐标按字典序规范方向；原弧长参数及法向被冻结。S/T 位移端点为0，作用于整段内部，不是单独移动端点。

原曲线即便已有 S 型也继续施加相对位移，可能增强或减弱局部弯曲。当前没有“识别原生 S 后跳过”的编码步骤。

检测首先在原曲线附近寻找路径：R0 搜索端点附近的连通路线，A3 按原站位寻找有序真实边缘点。缺失观测保留原 t 坐标，不把残片重置成完整0–1。错误对应与几何信息不足是不同问题。

## 当前评价口径

- 完整消息恢复 = 整条消息全部正确 / 全部尝试；错误和擦除都记失败。
- 逐 bit 正确恢复 = 正确读回的位数 / 全部写入位数；擦除位记未恢复。
- 接收后 BER = 已接收错误位 / 已接收位，同时必须报告擦除率。
- clean 没有消息真值；与独立均匀目标消息相比，逐 bit 期望50%，完整k-bit期望2^-k。始终输出0也可获得50%，故它只是无关联对照，不能证明可用信道。
- 同内容各消息共用 prompt/seed/初始噪声，比较输出是否随真实写入变化；接收器不得读取真实消息。预测分布是否均匀与是否传递消息是两回事。
- 若要求每图固定长度输出，需显式报告“强制判决”与擦除回填规则。当前原始接收器会擦除，本包不偷偷随机补位。

## 本包用于审阅的重点

请核对是否接受“原曲线参考辅助”作为当前接收条件；是否认可先做单曲线低载荷通信，再做多载体纠错；是否将 MAT 保持为对照分支；是否保留图像质量约束。上述条件在结果解释中显式披露，不把更强辅助下的结果称为仅Mask恢复。
