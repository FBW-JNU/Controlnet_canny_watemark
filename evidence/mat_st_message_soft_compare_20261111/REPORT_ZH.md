# G1–G3使用PiDiNet-soft MAT的配对比较

全部图像（原实验产物：`index.html`） · 指标（原实验产物：`comparison.json`） · 协议（原实验产物：`protocol.json`） · 审计（原实验产物：`completion_audit.json`）

沿用二值MAT V2的10个开发内容、原曲线、32px局部缺口、S/T四个2bit码字、约1.5px名义位移和相同接收器。软化使用旧学习转换器的PiDiNet-soft分支；先遮盖Canny，再转换，并清空转换图中的孔。两种soft结构各使用已有800步权重、原验证阈值0.45，无训练或阈值调优。模型未接收源RGB。

G1无消息，G2在普通修复后投影，G3在修复过程中以相同V2阈值对齐BCE/系数/面积损失优化W+96步后投影。G3raw表示已使用消息约束、硬化后但未投影的输出。所有模型权重冻结，最终二值图缺口外恢复原Canny；连续soft合成图另存。

## 解释范围

- 比较的是不同旧领域权重及转换管线，不是仅改变同一模型输入的单因素实验。Refiner也有单独权重。
- Soft模型W+映射在autocast内初始化，逐例与旧标准soft前向完全一致；二值V2映射在autocast外，因此还存在初始化数值精度差异。
- 接收已知原始局部曲线和参考系数，不是随机RGB无参考盲检。四个合法码字没有认证冗余。
- 投影显式重建S/T曲线，不能把投影后的成功全部归于MAT生成；必须查看G3raw。
- 本次使用先遮盖再转换；没有测试完整Canny先转换后遮盖，也没有测试原图原生PiDiNet soft输入。

## 结果判断

本轮近似soft管线没有显示提升。相同10内容、32px缺口下，二值MAT V2 / soft native / soft refined的G2完整2bit分别为36/40、8/40、8/40；G3投影前为34/40、32/40、30/40；G3投影后为35/40、35/40、34/40。G3raw正确且判存在分别34/40、31/40、30/40，不能把最近码字标签正确自动算作已确认水印。G4原始直接编辑保持40/40（判存在39/40）。

G1普通修复的几何接收从二值6/10降为soft两结构均1/10。孔内以原Clean Canny为参考的容差1px F1分别0.9213、0.2629、0.2644；原曲线骨架对应为0.9019、0.2066、0.2153。Soft视觉上的灰度连续没有转化为正确二值轮廓。G2、G3raw、G3相对同消息G4的孔内形状诊断也未提高。G0/G1的探索性误报各组均0/10，但soft G1有9/10几何擦除，这不是低误报保证。

Soft native/refined相对二值基线的G3raw正确率差为-5/-10个百分点；按10内容配对bootstrap95%区间为[-20,+10]、[-27.5,+2.5]个百分点。G3投影后差为0/-2.5个百分点，区间[-10,+12.5]、[-10,+5]。这些小样本开发结果不支持优于基线，也不足以作等效或普适退化结论。投影前四码字均正确的内容数为二值7/10、native7/10、refined5/10。

### 投影支撑的额外审计

投影支撑审计（原实验产物：`projection_support_audit.json`）发现，G3投影成功但所选支撑点全部位于缺口外的次数为二值1/40、soft native3/40、soft refined4/40；其中soft两结构各2次在硬化后的缺口内完全没有前景像素。原project_v2候选管道比缺口更宽，可能沿孔外邻近曲线获得支撑，再用已知源曲线显式重建码字。因此，“有受支持候选”并不保证MAT已在目标缺口内补出了目标线。保留原投影算法和全部原始分数以维持对照，没有按此审计删除失败或重算原门槛；该问题进一步说明投影后可读率不能全归因于MAT生成。审计是发现空孔后增加的故障诊断，不是事先校准的接收规则。

### 范围与下一步

两种soft结构均未达到G3的40/40输入门槛，未生成RGB，没有RGB恢复率或RGB质量结论。当前只验证“破损Canny→旧学习转换器→旧pidi_soft MAT→0.45阈值”这一条管线，不能据此断言所有soft表示无效。转换图呈宽灰带，硬化后容易形成宽块、短段或空孔；W+96步约束也未保证完整细线。若继续改进，应先在独立验证集处理转换域与细Canny的差异、输出连通性及投影支撑必须来自孔内的问题，再检查真实二值闭环。

本轮没有训练或微调模型。Soft和二值使用不同旧领域权重，soft W+初始化与旧标准前向精确一致，而二值V2的映射混合精度位置不同；因此不是仅改变输入软硬的单因素比较。全部原内容、mask、码字、检测门槛与G0/G4保持一致，旧实验未覆盖。


## 固定内容目视检查

固定检查selection序号0、1、8、9（018495、025148、129246、133667），每个内容四消息。四行四列复核图为panels/*_comparison_review.png，列依次为二值G3raw、soft native G3raw、soft refined G3raw、G4。页面还提供G1连续soft与硬化结果、G2/G3投影前后并排图。这是开发中的定性诊断，不是盲审或人工成功率。

018495：近似soft输入呈宽灰带，G1硬化后局部形成宽块和粘连。两种soft的G3raw在部分消息下只剩零星短段或完全空孔；投影后可因邻近孔外轮廓支撑而被重建，不能误认为MAT直接补出曲线。

025148：native的四消息均有明显缺段，refined的m10/m11比native补出了更多细线，但m00/m01仍为空缺。局部改善没有转化为全内容稳定恢复。129246：三种模型的G3raw都能产生不同弯曲形态，较单纯孤立曲线表现好，未见soft一致优势。133667：soft native的m00出现明显中断，refined m00也有较弱或缺失的连接，其他消息局部较连续；与二值基线相比没有一致改善。

总体观察与二值指标一致：soft图的平滑外观、存在部分可写曲线，并不等于硬化后可靠的四码字闭环。应同时看全部失败和G3投影前输出。
